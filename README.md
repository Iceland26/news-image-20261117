**THE WORLD TODAY** — the whole of Tuesday 17 November 2026 on one broadsheet front page, drawn and typeset entirely by a single Python program. A masthead and dateline; the Kerch Bridge strike as the hero story with an illustrated panel and a dotted world map ("Where It Happened"); a mined tanker in Hormuz and the Manila summit as illustrated second leads; and an In Brief grid covering JPMorgan's outage, Nvidia's post-Huang earnings, the Vulcan failure, the Pentagon's ninth failed audit, Estonia's border closure and the 1.5°C warning. Pure standard library: the program ships its own stroke typeface, its own renderer and its own PNG encoder, needs no network, and produces a byte-identical 1024×1024 PNG on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024×1024, ~190 KB). Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.png`.
